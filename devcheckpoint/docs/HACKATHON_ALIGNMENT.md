# Hackathon Track Alignment

DevCheckpoint is intended for:

**Track 3 — Developer Tooling**  
**Workflow & Context Management**

The project focuses on reducing context switching by preserving development task state and making that state easy to resume or hand off.

The differentiator is not Git history itself. The product captures the context around unfinished work:

```text
intent
blocker
attempts
relevant files
errors / notes
next action
```

This makes the product a workflow/context tool rather than a replacement for Git or an ordinary AI code assistant.
