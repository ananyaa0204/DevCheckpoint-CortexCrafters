# Screen Map

Approved design-reference screens are stored under `design/references/`.

## Core Screens

1. `dashboard.png` — overall current-work summary
2. `add-project.png` — select and validate local Git repository
3. `project-workspace.png` — project Git status and active task
4. `start-task.png` — create a development task
5. `task-detail.png` — task overview and progress
6. `code-changes.png` — changed files and diff view
7. `discussion.png` — task discussion/activity
8. `save-checkpoint.png` — checkpoint capture and AI generation
9. `checkpoints.png` — checkpoint history/list
10. `checkpoint-detail.png` — detailed checkpoint state
11. `resume-task.png` — restore working context
12. `handoffs.png` — handoff list/detail
13. `create-handoff.png` — generate a handoff from checkpoint
14. `analytics.png` — optional development insights
15. `settings.png` — local model and product preferences
