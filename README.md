# DevCheckpoint

**Git saves your code. DevCheckpoint saves the context around your code.**

DevCheckpoint is a local-first developer productivity tool that helps developers save and restore the working context around a coding task.

When developers get interrupted, switch projects, or return to work later, Git can show what changed, but it does not always explain:

- what you were trying to do
- what was currently broken
- what you already tried
- which files mattered most
- what you planned to do next

DevCheckpoint captures that context and turns it into a checkpoint that can be resumed later.

---

## Core Workflow

```text
Select Local Repository
        ↓
Start Task
        ↓
Work Normally
        ↓
Save Checkpoint
        ↓
Collect Git Context
        ↓
Sanitize Sensitive Data
        ↓
Generate Structured Context
        ↓
Save Locally
        ↓
Resume Development Later
